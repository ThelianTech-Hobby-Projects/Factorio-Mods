# Coding and Data Standards

**Status: Placeholder / Planning Required**

## Current status

The legacy Thelian Industries planning files do not establish coding conventions, data-definition standards, naming rules, formatting rules, review requirements, or compatibility standards.

No standards are invented during this migration.

## Narrow Electronics data constraints

The [Electronics decision record](../Plans/InProgress%20Plans/TI_Electronics_Plan.md) establishes stable compact PCB planning IDs (`pcb-1`, `pcb-2`, and `pcb-3`) for the Phenolic, Fiberglass, and Ceramic families; final prototype-ID normalization remains an implementation decision. Separate crude, prototype, native, or improved recipe prototypes may share one canonical item output. No broader naming, formatting, registration, or compatibility convention is inferred from these constraints.
