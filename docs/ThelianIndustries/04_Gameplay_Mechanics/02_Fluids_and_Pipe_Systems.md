# Fluids and Pipe Systems

**Status: Idea / Research Needed — No Canonical System Specification**

## Current status

The legacy planning set contains fluid and pipe-system concepts only as speculative content in `Mods/ThelianIndustries/plans/IDEAS.md`. It does not define an approved network model, transport rules, compatibility behavior, or final implementation approach.

The [Idea Backlog](../Plans/Idea_Backlog.md) remains the authoritative owner of those concepts. This page is a reserved documentation location; it does not duplicate the proposals or treat them as accepted design.

## Research boundary

Any feasibility assessment must remain separate from a design decision. The audit-derived research baseline is tracked in [Technical Feasibility Research](../06_Research/01_Technical_Feasibility_Research.md); it is not a commitment to implement a pipe system.
