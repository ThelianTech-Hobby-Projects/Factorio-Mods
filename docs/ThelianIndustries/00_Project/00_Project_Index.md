# Thelian Industries Project Index

**Status: Planning Draft**

Thelian Industries is described by the legacy source set as a Factorio Space Age overhaul modpack. Current owner-designated plans contain locked architecture for metallurgy and electronics plus a locked research-system foundation; Stage 1 progression, solar-system concepts, and the idea backlog provide additional planning material, while several intended domains still have empty or incomplete dedicated sources.
