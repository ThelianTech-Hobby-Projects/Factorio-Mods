# Architecture Decision Records

ADRs record explicit owner-approved, durable decisions and their rationale. They are not a mechanism for promoting an idea, a planning draft, or an unresolved review item into a decision.

No substantive ADRs exist at the initial migration point. When one is authorized, create it from the [ADR template](../../Templates/adr-template.md), link its supporting evidence, and update the relevant canonical document and changelog.
