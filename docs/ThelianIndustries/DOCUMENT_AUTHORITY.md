# Document Authority

This document distinguishes authority for two different questions. A plan is not evidence that the mod currently implements a behavior.

## Actual Implemented Behavior

For claims about what Thelian Industries currently does, consult sources in this order:

1. Current accepted source code and data definitions.
2. Current automated tests.
3. Current verified runtime or playtest evidence.
4. Canonical documentation after verification.
5. Plans and historical material.

Do not state that a planned feature is implemented unless the repository, tests, or verified runtime evidence supports that statement.

## Current Planned Design Direction

For claims about intended design, consult sources in this order:

1. Explicit owner-approved canonical Thelian Industries documentation.
2. Accepted ADRs or decision records.
3. Current canonical planning drafts that clearly state their planning status.
4. Review evidence.
5. Active plans and backlog.
6. Archived or historical material.

During this initial migration, most material is planning-stage. Use the status labels defined in [the documentation root](README.md#status-vocabulary) and do not infer `Locked` merely from confident legacy wording.

## Owner Resolution During Migration

The explicit owner resolutions dated 2026-09-04 supersede conflicting legacy wording for the migration. Their application and remaining open design direction are recorded in the [migration audit](Reviews/migration_audit_2026-09-04.md).
