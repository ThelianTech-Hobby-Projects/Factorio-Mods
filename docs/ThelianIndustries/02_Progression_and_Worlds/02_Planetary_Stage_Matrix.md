## Name normalization and provenance

- `Navius` in the legacy solar-system source is shown here as **Nauvis**.
- `Aquilio` in the legacy progression and solar-system sources is shown here as **Aquilo**.
- `Archo-Nexus` in the legacy sources is shown here as **Archo Nexus**.

These are owner-approved migration normalizations. See [Solar System and Planets](01_Solar_System_and_Planets.md) for the detailed source material and [Game Progression](00_Game_Progression.md) for stage ownership.
