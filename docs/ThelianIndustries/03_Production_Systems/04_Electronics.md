## Scope and ownership

This document owns electronics-specific component use and progression. The material-production concern for shared components is owned by [Metallurgy Processing Chains](01_Metallurgy_Processing_Chains.md); that document links back here.

## Current Implementation Status

**Implementation status: Docs Ahead of Implementation / Localization Only with unregistered scaffold.**

No TI wire, solder, PCB, circuit board, resistor, capacitor, transistor, diode, microchip, CPU, power-supply, electronics assembler, recipe, or technology prototype is registered. The inactive `ti-electronic-components.lua` source is behind a commented loader and contains seven duplicate `name = "n"` item tables, so it is not a viable registered implementation. English locale vocabulary is not implementation evidence.

The exact evidence and localization drift are in [Project Context Snapshot](../PROJECT_CONTEXT.md#8-electronics-snapshot).

- Electronic Components: Wires, Boards, Microchips, CPUs, Power Supplies.

It lists Copper, Tin, Lead, and Wood/Stone as inputs to create electronics components; Resistors, Capacitors, Transistors, Diodes, Integrated Circuits, and Circuit Boards as new electronics components; and an Electronics Assembler as a new electronics machine. This is progression context, not a complete electronics-chain or recipe specification.
